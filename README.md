# Clinwide — окремий презентаційний сайт

Самостійний мінісайт продукту. Розміщений поруч із `clinic-card-demo`, має власні залежності й запуск. Не використовує Supabase, дані пацієнтів або акаунти клініки.

## Як переглянути

1. Відкрийте папку `clinwide-site` у редакторі.
2. У терміналі цієї папки виконайте `npm install` (залежності вже встановлено під час створення).
3. Виконайте `npm run dev`.
4. Відкрийте http://localhost:3003.

Для перевірки готової збірки: `npm run build`, потім `npm start`. Зупиніть попередній сервер на цьому порту перед запуском другого.

## Що є на сторінці

- огляд користі для рецепції, лікаря та власника;
- три перемикні ілюстрації: розклад, картка пацієнта, фінанси;
- сценарій роботи від запису до наступного огляду;
- пояснення доступу з телефона, планшета та комп’ютера;
- умови продажу й доплата за чатбота;
- калькулятор базової вартості Clinwide та підписок Cliniccards / iClinic;
- FAQ, місця для кейсів і справжніх відгуків;
- конструктор запиту, який можна скопіювати автору;
- метадані для пошуку, картинка для поширення посилання й іконка бренду.

Контакти, портфоліо та цитати не вигадані. Поки контакт не заданий, кнопка копіює текст, але не надсилає його. Є ручне копіювання, якщо браузер блокує доступ до буфера обміну.

## Як додати власні матеріали

`src/lib/brand.ts` — назва й короткий опис. Назву Clinwide обрав власник; перевірка її правової доступності не проводилась.

`src/lib/product-site.ts` — ціни пропозиції, посилання на тарифи конкурентів і дата перевірки. Дані порівняння потрібно оновлювати перед публікацією та надалі при зміні тарифів.

`src/app/page.tsx` — тексти, FAQ та місця для кейсів і відгуків. При заміні заповнювачів додайте тільки погоджені матеріали клієнта.

За потреби скопіюйте `.env.example` у `.env.local` і заповніть:

```dotenv
NEXT_PUBLIC_PRODUCT_CONTACT_URL=
NEXT_PUBLIC_PRODUCT_PORTFOLIO_URL=
NEXT_PUBLIC_DEMO_URL=
NEXT_PUBLIC_SITE_URL=
```

Контакт: HTTPS-посилання, `mailto:` або `tel:`. Портфоліо: HTTPS-посилання. Демо: адреса окремої робочої системи; локально дозволені localhost / 127.0.0.1. `NEXT_PUBLIC_SITE_URL` — остаточна публічна адреса сайту для коректного поширення посилань. Після зміни цих значень перезапустіть сервер або перебудуйте сайт. Не копіюйте сюди `.env.local` клінічної системи та її секрети.

## Перевірки

`npm run check` — перевірка типів і стилю коду.

`npm test` — браузерні перевірки для комп’ютера та телефона, включно з шириною 320 px, калькулятором, FAQ, перемикачами та відмовою буфера обміну.

`npm audit` — перевірка залежностей.

Результати й джерела: `docs/IMPLEMENTATION.md`. Публікація на зовнішньому хостингу ще не виконувалась.
